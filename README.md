# StyleDecor

A full-stack decoration service booking and management platform built with the MERN stack.
## Live link: https://stylede-3b386.web.app/
## Problem & Solution

Finding decorators, managing event bookings, and coordinating tasks based on location and availability can be challenging.

StyleDecor solves this by providing a centralized platform where customers can book decoration services, admins can assign tasks to available decorators, and decorators can manage their assigned bookings from acceptance to completion.

## Key Functionalities

- **Service Booking:** Visitors can browse services, while registered users can book decoration services for different events and locations.
- **Role Management:** Three roles — Admin, User, and Decorator. Users can apply to become decorators, and admins can approve their requests.
- **Task Assignment:** Admins assign bookings to available decorators based on their service areas.
- **Booking Workflow:** Decorators can accept or reject assigned tasks and update their progress through different stages until completion.
- **Availability Management:** Decorators become available for new orders after completing their current tasks.
- **Payment & Revenue Sharing:** Stripe integration for payments, with 90% allocated to decorators and 10% retained by the platform.

## Technology Stack

- **Frontend:** React.js, JavaScript, Tailwind CSS, DaisyUI
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** Firebase Authentication
- **Payment:** Stripe
- **Deployment:** Vercel, Firebase Hosting

## Core Focus

Role based authorization, RESTful API development, booking lifecycle management, location-based task assignment, decorator availability handling, and payment integration.
